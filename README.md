# EDABIP Expense Tracker

A local-first personal expense tracker built with React and TypeScript. Expenses and the selected theme are stored in the browser's localStorage; no backend or account is required.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Features

- Add, edit, and delete expenses with typed categories and optional notes
- Filter by category, date period, and search; sort by date, amount, or category
- Monthly spend, highest expense, and most-used category summaries
- Persist data locally and switch between light and dark themes
- Export the full expense list to CSV

All application source files are TypeScript (`.ts` or `.tsx`).
